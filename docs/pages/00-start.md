# Get started

Origami runs on Macs with Apple silicon (M1 or later) and macOS 15 or later.

## Install

1. Download [Origami.dmg](Origami.dmg), open it and drag Origami to Applications. It is for Apple silicon only (M1 or later), macOS 15 or later.
2. Open Origami from Applications. It is signed with an Apple Developer ID and notarized by Apple. macOS asks once whether to open an app downloaded from the internet: click **Open**.

The app includes ffmpeg, which it uses to read and export video, so there is nothing else to install. [Supported formats](supported-formats.html) lists the video, picture and sound files it reads.

## Your first video

Click New project on the launch screen, or press ⌘N, and give it a name. Origami makes a folder with that name holding an `edit.js` script and opens it. [Basics](basics.html) walks through what to write in it.
